# Loto

Application pour suivre les parties de loto.

- **Windows** : [Loto-Setup.exe](https://github.com/Anthoo06/App-Loto-Release/releases/latest) — lancez-le, l'app s'installe avec un raccourci sur le Bureau.
- **Android** : [Loto.apk](https://github.com/Anthoo06/App-Loto-Release/releases/latest/download/Loto.apk) — ouvrez le fichier sur le téléphone et autorisez l'installation si Android le demande.

L'application propose elle-même les nouvelles versions.
